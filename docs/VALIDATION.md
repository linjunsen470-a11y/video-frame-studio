## 开发中实际发现并修复

- 初始版本漏掉 OCR 框左侧的「今」，而修复后 OCR 也没检出残留单字。已增加两端相邻笔画搜索、
  平滑背景颜色残差提取、疑似孤立描边检查及局部放大复检；真实首帧已达到 100% 字幕像素覆盖。
- 原精细分割在部分平滑字幕图退化为整框。修复后代表帧 0/6/12/48 无 polygon fallback，均覆盖全部字幕。
- 羽化可能侵入保护区。最终合成后恢复保护区原像素并将该区从最终 Mask 清零，已通过模拟整图乱改的反例。
- 不合法 OCR 响应曾可能被解释为空文本。现在必须匹配字段且一致，坏响应不能通过质检。
- API 预算不足曾无法通过增加预算续跑。现在保存可恢复状态、保留缓存并复用已完成排序/帧，测试通过。
- 0 张成品的质检、NaN/Inf 资源限制、9/14/48-bit 格式检查、旧候选缓存计量等边界已修复并回归。
- 避免新版 PySceneDetect 自动安装 GUI OpenCV，选择实测兼容的 0.6.7 + headless 组合。

## 依赖与输入检查

Python 包安全扫描先发现 Pillow 12.3.0 / pip 25.0.1 的已知漏洞记录，升级至 Pillow 13.0.0 / pip 26.3 后，
`pip-audit` 当前返回 **No known vulnerabilities found**。这只代表当次 Python 依赖公告匹配结果，
不包含对系统 FFmpeg、模型供应链或所有业务逻辑的完整安全审计。

测试验证了拒绝私网 URL/混合 DNS/私网重定向、路径逃逸、HDR/高色深、异常尺寸和 OCR 失败等场景。
URL 下载器采用基础地址检查，并没有做 DNS/IP 连接固定；只用于可信用户提供的媒体，不应直接作为公网抓取服务。
本项目没有 Web 服务入口。
