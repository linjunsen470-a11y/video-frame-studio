# 验证与复现

在托管 Codex Cloud 工作区执行。冒烟测试需要 FFmpeg 和 Noto CJK 字体。

```bash
python -m pytest -q
python scripts/smoke_test.py --workdir /tmp/vfs-smoke-new
```

## 自动化覆盖

- 候选准备、显式选帧、续跑、重复图检查和历史 PNG 审计。
- 真实 RapidOCR、字幕蒙版、真实文字保护、掩码外零像素改动、残字误报回归。
- 官方 SDK 请求类型、整帧双区域编辑、返回配准、缓存、预算、重试和错误脱敏。
- 小红书竖图、横帧配对、JPEG 压缩、源图哈希和文案审计。

冒烟测试生成一段 8 秒的无损合成视频。程序先准备候选，再显式选择 3 帧，使用模拟模型测试整帧编辑入口。真实 OCR 参与质检，并核对字幕真实像素覆盖、保护区和掩码外像素。完成后验证续跑和 `--qc-only`。运行报告保存在本地测试目录。

## 真实项目核查

整帧模式已在一段配送视频上验证。三帧均去除了经确认的叠加字，修复 PNG 的掩码外改动均为 0。仓库清理后重新读取此前的真实模型响应，三张重新导出的 PNG 与此前结果逐字节相同。小红书 JPEG 图集与文案也通过独立审计。此次回归核查使用本地缓存，没有发起新的付费请求。

这组结果只代表所测素材。整行文字漏检、模型回图错位或掩码内修补不自然时，仍需要人工检查。
