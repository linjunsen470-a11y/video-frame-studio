## 原帖里值得借用的写法

**标题留一个具体理由让人点开。** 海口盒饭用城市、每份价格和预订状态说明这篇对谁有用，正文再列当天的主菜与可选加菜。长沙工作餐推荐从预算切入，正文用十来位同事凑单、几菜一汤和可选餐标回应。写广州企业餐时，可以把最影响询单的确定信息放标题，选项和细节放正文。 [海口盒饭菜单](https://www.xiaohongshu.com/explore/689ecb1b000000001b021d51) · [长沙工作餐体验](https://www.xiaohongshu.com/explore/697090e1000000001a02bfd5)

**真人感往往来自事情怎么发生。** 西电广研院的团餐经验先交代校门开放后哪些配餐可以送到，再讲自己试了多久。另一条订餐反馈把迟送、送错地方和忘送拆成几次具体经历。团餐商家可以借这种叙事顺序，写一个经确认的备餐或交接细节。 [西电广研院团餐指南](https://www.xiaohongshu.com/explore/6ae700900000000025018904) · [订餐体验](https://www.xiaohongshu.com/explore/6a58bef30000000009035e11)

**把过程里的一个变化写出来。** 潮汕小饭桌的作者按企业、学生和散单拆开当天 67 份订单，讲忙不过来和米饭没煮够，再列三套实际菜单。另一个盒饭作者把早上买菜、中午送试吃写成一条时间线。自己的订单如果没有插曲，也可以从一处真实动作讲起，例如汤放在哪里、同一时间怎么分两拨发餐。 [小饭桌出餐记录](https://www.xiaohongshu.com/explore/69219ea2000000000d03fe9f) · [写字楼试吃后续](https://www.xiaohongshu.com/explore/6ab4ab4d000000001301ad92)

**看看订餐人用什么词。** 行政求助写了团队规模、长期用餐、同事偏好和预算拉扯，这些都比「省心高效」更接近真实采购。回复此类需求时，一条笔记可专说临时加减份、套餐差异或错峰发餐。先选当前素材能证明的一项。 [行政求助](https://www.xiaohongshu.com/explore/6970e40e000000001a02616c)

**话题区里的词有不同用途。** 长沙案例同时带城市、团餐和工作餐词，企业茶歇盒用企业茶歇与开店记录交代内容类型。本项目默认只留能帮读者确认城市、品类或用餐场合的标签。标签多寡及先后没有曝光数据可比较。 [长沙工作餐体验](https://www.xiaohongshu.com/explore/697090e1000000001a02bfd5) · [茶歇盒标题与话题](https://www.xiaohongshu.com/explore/6a92f94d00000000060120da)

## 写法怎么落到本项目

| 信息在手 | 标题写什么 | 正文先说什么 | 适合的结尾 |
| --- | --- | --- | --- |
| 看得见菜、分格盒和装盒台 | 地域＋品类＋开盖或装盒 | 一盒里真正可识别的菜，或分装动作 | 停在具体现象，或接一句订餐用途 |
| 确认了会议中场发餐 | 地域＋会议餐＋一个发餐条件 | 参会的人什么时候、怎么拿到一份 | 问会议时间、人数或取餐点 |
| 确认了工厂两个班次 | 地域＋员工餐＋班次 | 两次领餐如何安排 | 请对方提供实际班次 |
| 已核对起订、价格或区间 | 地域＋品类＋一个筛选条件 | 解释条件对应什么搭配或服务 | 请对方给能确认下一步的信息 |
| 确认是临时加班或临时补餐 | 地域＋加班餐＋一个具体安排 | 大家在哪儿拿饭、怎么分发 | 用真实的时间点或动作收束 |

### 去掉三句最容易写成套话的地方

| 原写法 | 可以怎么落地 |
| --- | --- |
| 「用专业团餐解决企业用餐需求」 | 交代何时吃这顿饭，比如「会议中场发午饭，一人领一盒」。 |
| 「荤素搭配、营养均衡、品质保障」 | 写一处可见的菜和包装，比如「番茄炒蛋和青菜各占一格」。 |
| 「欢迎咨询，可根据需要定制」 | 给对方下一步，比如「订会务餐，告诉我几点散会、大概几个人」。 |

话题标签默认两到四个。先留城市或服务品类，再选正文真正写到的场景。只有菜盒照片时，`#广州团餐 #员工餐配送 #公司午餐` 已经说清对象。写的是开会中场发餐时，场景词换成 `#会议餐`。餐饮商家名、城市、价格和起订条件来自自身业务确认。
