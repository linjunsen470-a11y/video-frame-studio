# 餐饮配送文案指南

## 第一遍从素材找卖点

先找图中可见的菜、包装和动作，再对照用户确认的业务。写作前选定说话的人和他要帮读者做的一个决定。商家号可以直接介绍服务。涉及合作伙伴素材时，根据授权表述照片、订单和说话人的关系。作者亲历、日期、客户反馈和业务范围都要有依据。

- **一顿饭怎么安排。** 有份数、发餐点、时间或分批要求时，挑一个真正影响安排的条件切入。会议中场、两班换班、临时加班对应的是不同问题。
- **掀盖看到什么。** 从读者视角找最想确认的一点。照片上有两格肉菜时，可以写清搭配。只写番茄炒蛋和青菜，容易让人误以为就这两样。肉类品种或做法拿不准时，用能确认的「肉菜」。
- **这一批怎么做。** 有确认过的项目资料时，用一个真实变化串起来，比如不同班次如何领餐。素材只到装盒时，正文也写到装盒。
- **现在能怎么订。** 覆盖区域、餐标、起订条件、订餐时限有筛选价值，挑一项已经确认并能帮读者判断的信息。报价待定时可让读者带上人数或用餐时间。

## 标题

先选标题要帮读者做什么。采购意图明确时，写地区、品类和一个选餐条件。封面有特别充实的菜盒、摆台或发餐画面时，可以把这个具体看点提到标题。广州业务默认保留「广州」，有明确范围时再写区名。问句要在正文前几句回应。数字要核对其适用范围。

| 已有事实 | 标题方向 |
| --- | --- |
| 广州会议餐，盒饭和汤分别装 | 广州会议盒饭，汤单独发 |
| 广州工厂员工餐，两班在不同时间取餐 | 广州工厂员工餐，两班怎么发 |
| 广州员工餐，封面四格都是菜 | 广州公司订盒饭｜四格都是菜 |

## 正文和收尾

- 起句写一件读者在意的事。菜品可以从口感线索、搭配和分量写起，业务说明可以从确认过的餐标或服务条件起笔。已确认实际发生时才用「这次」「今天刚送」。
- 正文承接标题，用一两处具体事实多说一步。封面已经看见一排餐盒，正文可以讲它如何适合办公室按人发餐。每句尽量提供新信息，句长随意思走。
- 允许直接推荐、说自己做什么、邀请询价。把营销信息写成商家能回答的下一步。价格待定时可以写「想问菜单或价格，发个区名和大概份数」。询单所需的信息因内容而异。现场记录可停在具体做法或画面。
- 正文默认 80–150 字，信息少时可以更短。图标视内容使用。价格、路线、温度、份数、出锅时间、复购和资质只写到证据支持的程度。

## 话题标签

默认两至四个。优先让每个标签各自承担本地服务、实际品类或用餐场合的作用。广州员工午餐可用「#广州团餐 #员工餐配送 #公司午餐」，广州会议盒饭可用「#广州团餐 #会议餐 #公司订餐」。实际涉及工厂时再加「#工厂员工餐」。删掉和该读者无关的泛热门词、近义重复和其他城市名。

## 第二遍按买家视角审稿

1. 先看标题和正文的信息顺序。如果标题像在给照片起文件名，把真正影响读者选餐的细节提前。正文第一句接住标题，再补能影响询单的信息。
2. 逐句看这句话有没有告诉读者一件新事。删掉逐图报幕、意思重复和程序化的结尾。「剩几份也数得清」这类解释如果没有回应实际订餐顾虑，可以省掉。
3. 朗读一遍。卡住的地方先挪动主语、拆长句或改成商家平常会说的问法。通顺的句子和有效的卖点保留。用户给了满意的自写样例时，参考其称呼、句长和邀请询单的方式。
4. 把数字、餐品、服务条件和现场细节与原始素材核对一遍。报价的适用范围、交接安排和订单出处尤其容易在润色时被写宽。发布稿保留标题、正文及话题。

## 能借用的原帖动作

- 长沙团餐体验写到十来位同事凑到起送量，还留意到餐具里带了漱口水。写员工餐时可同样选一个能解释购买或分发的细节。给自己的读者看自己实际的餐盒与配套。 [原帖](https://www.xiaohongshu.com/explore/697090e1000000001a02bfd5)
- 行政下午茶记录写到 25 人、约几点到，以及哪盒点心剩下了。写会务或茶歇复盘时，可以用一处真的发生过的选择或变化拉动正文。 [原帖](https://www.xiaohongshu.com/explore/6a30aebb000000000701198f)
- 校园团餐推荐先说校门开放后为什么多了送餐选择，再说试过的餐。多个样本里都能用这种顺序，先讲这一顿的条件，接着讲选项。 [原帖](https://www.xiaohongshu.com/explore/6ae700900000000025018904)
